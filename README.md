# Freelance Management System

A console-based application to help freelancers organize their projects, track deadlines, and manage client information efficiently.

## Version

**v1.0.0** - Initial Release

## Features (Iteration 1)

This version implements the following functional requirements:

- **FR1: Create New Project** - Add new projects with client information and descriptions
- **FR2: View All Projects** - Display all projects with their current status
- **FR3: Add Deadline to Project** - Set deadlines for projects to track deliverables

## Technology Stack

- **.NET 8.0** (or higher)
- **C#**
- **JSON** for data persistence

## Project Structure
```
FreelanceManagementSystem/
├── FreelanceManagementSystem.csproj   # Project configuration
├── Program.cs                          # Main entry point and UI
├── FreelanceManager.cs                 # Business logic layer
├── Project.cs                          # Project model
├── Deadline.cs                         # Deadline model
├── projects.json                       # Data storage (auto-generated)
└── README.md                           # This file
```
